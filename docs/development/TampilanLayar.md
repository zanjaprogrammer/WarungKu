CORE SCREENS (JANGAN TAMBAH)
1. Home (Hari Ini)

Struktur wajib:

Zona 1 (paling atas):

“Uang Sekarang” ditampilkan besar (hero card)

Zona 2:

Tombol aksi cepat:

Jual

Tambah Stok

Pengeluaran

Zona 3:

Ringkasan hari ini (kartu kecil):

Penjualan Hari Ini

Pengeluaran Hari Ini

Stok Hampir Habis

2. Jual Barang

Grid produk besar

Tap = jual langsung (tanpa popup)

Long press = pilih jumlah

3. Stok Barang

List nama barang + sisa stok

Badge “Hampir habis”

Aksi:

Tambah stok

Penyesuaian stok

4. Tambah / Edit Barang

Field minimal:

Nama

Harga jual

Harga beli (opsional)

Stok awal

Minimum stok

5. Uang (Cash)

Saldo kas besar di atas

Riwayat uang masuk & keluar

Tombol catat pengeluaran

6. Daftar Belanja

Checklist barang hampir habis

Urut berdasarkan frekuensi penjualan
